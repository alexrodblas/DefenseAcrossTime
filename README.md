# DefenseAcrossTime
FPS Tower defense game developed with Unity. Multiple eras, enemies, turrets and progression system.
This Project was developed as an academic group project.

🎮 About the game

Defense Across Time combines first-person shooter mechanics with tower defense.

The objective is to defend a time machine against waves of enemies from different historical periods. Player can fight enemies directly using weapons or deploying turrets to protect the objective.

Three different eras:
- Prehistory: Humans with spears, mammoth
- Medieval Age: Skeletons with swords
- Future: Robots

🛠️ Technologies

Unity

C#

FMOD

Blender

💻 Main features

- FPS player controller and camera
- Enemy AI and movement behaviour.
- Melee and ranged enemies.
- Enemy wave spawning.
- Automated turrets.
- Time machine health.
- Multilingual support.

👨‍💻 My contributions

This project was developed as part of a group project during my Higher Vocational Training in Multiplatform Application Development (DAM - Video Games).

My main responsibilities included:
- Enemy AI: Implemented enemy movement and behaviour.
- Combat systems: Developed melee and ranged enemy attacks.
- Wave management: Implemented the enemy wave spawning and management systems.
- Camera system: Worked on the game's camera implementation.
- Accessibility and localization: Implemented multilingual support to make the game available in different languages(ES-EN-CAT).
